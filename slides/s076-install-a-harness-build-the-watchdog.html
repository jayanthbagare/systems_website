How you know you're done

The agent tells Kovacs and Guangzhou apart — and says why they need opposite responses.

EM owns the environment. If it runs on one laptop and not the others, you have a sandbox problem — and that is subsystem three, not bad luck.

Devs pair on tools · PM writes the alert acceptance criteria first · EM owns reproducibility

The instruction to write the system prompt as an investigation protocol is the whole lesson. 'You are a vendor health monitoring agent' produces nothing useful.

Push the PM to write acceptance criteria before any code exists. That is subsystem five arriving early, which is exactly right.

If a pod's agent calls every tool for every vendor, it works but it is not exercising judgement. Ask them what it would cost at ten thousand vendors.
