III · Subsystem 4

Memory/State

Systems · Constraints · Agents

Where progress lives between sessions. Outside the model's head, in a place you can audit.

If the agent is reasoning across many notifications over a shift, what it has decided, what it has deferred, and what it is unsure about must persist. Otherwise every session starts cold and quality is unstable.

State is also where humans intervene. They read what the agent has done so far, correct what is wrong, and the agent reads the correction on its next turn. State is the surface of collaboration.
