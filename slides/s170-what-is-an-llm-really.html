What Is an LLM, Really?

A philosophical pause before we prompt

An LLM is, at its core, two things:

Compression

of all human knowledge into weights

+

Search

through that compressed space at inference

Compression

Trillions of words

→

Billions of numbers

Training doesn't memorize — it distills patterns.

Grammar, facts, reasoning, style, tone — all compressed into a lossy statistical representation. Like a zip file of human language, except the decompression is probabilistic, not exact.

This is why LLMs "hallucinate" — the compression is lossy. Not every fact survives intact.

Search

Your prompt

→

navigates the compressed space

When you prompt, you're not asking a database. You're steering a search through a vast landscape of compressed patterns.

A better prompt = a better search query into this space. Context narrows the region. Examples sharpen the path. Temperature controls how adventurously it explores.

This is why prompt engineering works — you're not "tricking" the model, you're giving it better coordinates.

"All models are wrong, but some are useful." — George Box An LLM is the most useful wrong model we've ever built.
