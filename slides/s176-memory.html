III · And two primitives

Memory

Systems · Constraints · Agents

Short-term

The context window of the current session.

Useful for: the current notification, the conversation so far, the immediate task. Bounded. Forgotten when the session ends.

Long-term

Durable knowledge across sessions and assets.

Useful for: prior failures on this asset class, this supplier's quirks, this technician's notes, the plant's hard-won patterns. Built deliberately. Curated. Auditable.
