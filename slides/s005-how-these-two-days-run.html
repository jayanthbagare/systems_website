How these two days run

Systems · Constraints · Agents

A workshop about constraints should not run every station flat out.

Six labs, not six lectures

Around 60% of the two days is your pod at a keyboard.

Each block teaches just enough to start the lab, then stops.

The pod is the unit

You work as the pod you deliver as — PM, EM, developers.

Not as individuals. Not as a class.

One artifact per lab

Every lab ends with something you can show in ninety seconds.

No artifact means the lab did not happen.

The binding constraint in this room is facilitator attention, not slides. Two of us, eight pods — the labs are built to run without us.

Say this out loud: we redesigned this workshop using the thing we are about to teach.

The old version was 97 slides of talking. That is running the lecture station flat out while the learning station starves — exactly the failure mode in Block I.

Set the expectation that they will be working, not watching. Some pods find this uncomfortable at first. That is fine.
