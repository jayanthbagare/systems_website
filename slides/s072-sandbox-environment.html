III · Subsystem 3

Sandbox/Environment

Systems · Constraints · Agents

Where the work actually happens. Reproducible, observable, self-describing.

An agent that worked yesterday and fails today, with the same prompt, has an environment problem. Same model versions, same tool versions, same connector configurations, same data shapes.

In enterprise terms: the agent must run in an environment as carefully versioned as the systems it touches. This is unglamorous work and it is where a lot of agent demos die in production.
