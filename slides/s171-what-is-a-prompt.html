What is a Prompt?

PSG College of Technology, Coimbatore | LLM & AI Foundations

A prompt is the input you give to an LLM — the instructions, context, constraints, and examples that shape its response.

Anatomy of a Good Prompt

Role / Persona

"You are an experienced college administrator..."

Task / Instruction

"Create a list of all public holidays in Tamil Nadu for 2026"

Context

"This is for a college leave management system"

Format / Constraints

"Return as a JSON array with date, name, type fields"

Examples (Few-shot)

"Like this: {date: '2026-01-26', name: 'Republic Day', type: 'national'}"
