THE HANDBOOK MOVE

Run This on Any Problem

1

Imagine at the frontier

What would this be if the constraint didn't exist?

2

Kick it hard

Perturb without pre-judging. Let it leave its current basin.

3

Watch where it settles

Under honest scrutiny — not under the fantasy.

4

Commit at that altitude

Automation, agent, or frontier. Name it.

5

Then build accordingly

Automation → build it cheap. Agent → engineer the loop. Frontier → question the process.

THE ARTIFACT. The one slide they photograph. This is what turns the block from viewpoint into handbook.

A repeatable procedure they can run on their own problems later. Keep it clean, reference-card feel, not a talking slide. Read it once, slowly, then move to the worked example.

The move: imagine high, commit low, build accordingly.
